Two Worker transport bugs

  1. redirect: 'error' is unsupported in Cloudflare Workers. It threw before any provider request was sent. Bun accepted the same code, so offline repairs worked.
  2. The pricing Worker lacked global_fetch_strictly_public. Once a request could be made, the same-account gateway required this flag to avoid Cloudflare error 1042.

The transport now uses manual redirects and rejects every 3xx response without following Location. The optional Bobs source uses manual redirects and its existing non-2xx rejection. The pricing Worker configuration retains the public-fetch flag.

Cloudflare references: Request redirect modes and Worker-to-Worker fetch.

The remaining sUSD pool gap

The retired yvCurve-sUSD vault 0x5a770DbD3Ee6bAF2802D29a901Ef11501C44797A holds LP 0xC25a3A3b969415c80451098fa907EC722572917F. A direct batched DeFiLlama request for November 7–8 returned HTTP 200 with an empty coins object. Archived graph reconstruction rejected both days: Curve coin 3 reports balance 21038809705456997561199807622, but the pool holds 0 of that coin. These checks do not establish a valid LP price or a zero-valued price.

The targeted write-mode repair considered and claimed all four asset/vault day targets: zero inserted, four invalid, zero execution errors, zero deferred, no active claims left. Three previously absent queue entries were added. No existing prices were overwritten.

The live gateway can still return cooldown/overload responses or time out; the remaining API 503 is distinct from the fixed pre-request Worker error. A successful health request alone does not prove provider availability.

What the LP log means

  • lp-guard:skipped … RPC endpoint is cooling down: the extra LP check could not use the Ethereum RPC endpoint.
  • lp-guard:unverified … no-coin-price: it could not load every component price from storage.
  • Both paths currently return true. The quote can still be finalized. A finalized counter is not proof that this extra LP check passed.

This incident fix preserves that existing best-effort guard behavior. Production and warmup each have only one configured Ethereum RPC URL, so endpoint cooldown provides no alternate route. The pasted progress excerpt showed 291 completions after 350 claims; it was not a final whole-run summary.

Verification and scope

An authenticated temporary Worker reproduced 1042 without the public-fetch flag, then reached gateway readiness with it. The actual client separately reproduced Cloudflare's unsupported-redirect TypeError. After the transport fix, that client fetched the exact yBOLD observation through the gateway. Temporary diagnostic Workers were removed.

Typechecking passed. Regression cases were added for redirect handling and credential protection; tests and lint were not run locally, per repository instructions. No schema migration, new production service, or additional secret is required.

The fix is deployed operationally; merge the accompanying PR to preserve it in future main-branch deployments.

What remains protected

  • Current API quotes never fill past dates.
  • Historical graph validation, observation windows and Curve plausibility checks remain required.
  • Provider errors remain retryable failures, separate from confirmed missing observations.
  • Queue admission failures do not discard a valid API response.
  • Completion means an accepted finalized price exists for the target; it does not require a separate row from every provider.

Today's DeFiLlama misses can use a bounded on-demand Chainlink/on-chain fallback, with Enso when configured. Fallback quotes retain their source, remain provisional, and refresh on request even when a previous quote is stored.
